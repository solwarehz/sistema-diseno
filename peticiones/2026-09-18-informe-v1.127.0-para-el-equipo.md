# Informe v1.127.0 — para Control Administrativos V2.0

**18 de septiembre de 2026** · MMI-DS **v1.127.0**, publicada y verificada por
las dos vías.

```bash
npm install "github:solwarehz/sistema-diseno#v1.127.0"
```

**Esta versión no añade nada al código.** Es lo que salió al preguntar en serio
si lo que se **entrega** es lo que se **promete**. Los veinte pasos estaban en
verde todo el tiempo.

---

## 1 · Lo primero, porque les afecta hoy

**Si montaron el sistema siguiendo el §3 del LEEME del ZIP, les falta una línea
y los componentes les están saliendo sin estilo.**

```ts
import 'sistema-diseno-ae/componentes.css';   // o la ruta relativa, si vino en ZIP
```

Ese paso **no estaba en la lista**. El §3 explicaba los colores, Tailwind y el
modo oscuro, y nunca importaba la hoja de los componentes.

**Y si actualizan copiando carpetas** (Ruta A del LEEME), ahora son **cuatro**:

```
sistema/tokens/
sistema/candado/
sistema/componentes/     ← la hoja y el contrato
componentes/             ← los componentes de React
```

Ponía **solo las dos primeras**. Con eso, los componentes y su hoja se quedaban
congelados en la versión vieja — que es justamente lo que cambia en casi todas
las versiones.

**Y su `tsconfig` necesita dos cosas que no estaban documentadas.** Medido con
`tsc` sobre el paquete instalado: sin `@types/node` salen **nueve** errores
—nuestros avisos de desarrollo leen `process.env`— y sin `"DOM.Iterable"` otros
tres. Next las trae por omisión, así que probablemente no lo han visto; un
proyecto Vite sí choca.

la única parte que envejece.

## 7 · Lo que queda declarado

1. **El motor de cascada no sabe contar hermanos**, y ahora lo dice: los
   selectores con `+`, `~`, `:nth-child` o `:has` se descartan **y se imprimen**.
   Hoy son seis en toda la hoja, y **ninguna regla con esos selectores está
   vigilada** por los candados de cascada.
2. **Ningún candado mira la prosa del LEEME ni la del catálogo.** Las nueve cosas
   del §2, §3 y §4 de este informe las encontró una verificación a mano. La tabla
   de páginas del LEEME sí se genera; el resto se escribe.
3. **Ningún candado mira el TEXTO de un bloque «copia esto».** Y la página del
   panel **no tiene ninguno**, siendo el componente de firma más difícil del
   sistema y el único de los recién cambiados que no lo tiene.
4. **`RangoFecha` solo aportó 13 elementos** a la comprobación del §6 porque el
   calendario arranca cerrado.
